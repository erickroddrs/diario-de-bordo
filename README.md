# Diário de aprendizagem

Este é o meu diário de aprendizagem da área de Informática, onde registo os conhecimentos adquiridos, as atividades realizadas e as dificuldades encontradas ao longo das aulas. Através deste diário, posso acompanhar a minha
evolução, aprender a utilizar diferentes programas e ferramentas informáticas, desenvolver competências digitais e melhorar os meus conhecimentos sobre as tecnologias. Este diário permite-me também refletir sobre o que 
aprendi, reconhecer os meus progressos e identificar os aspetos que preciso de melhorar, contribuindo para o meu desenvolvimento pessoal e profissional.
